# 📋 Projeto Lista de Tarefas - CodeFactory Solutions

## 📖 Descrição do Projeto
Aplicação web responsiva desenvolvida para o gerenciamento e organização de tarefas diárias. O sistema permite a inserção de atividades, categorização por prioridades (Alta, Média, Baixa) e marcação de conclusão, utilizando uma interface amigável e moderna.

## 🎯 Objetivo
O objetivo deste repositório é demonstrar na prática a adoção da Cultura DevOps para a empresa fictícia CodeFactory Solutions, solucionando problemas de padronização, versionamento e integração da equipe de desenvolvimento através de ferramentas de controle de versão.

## 🚀 Tecnologias Utilizadas
* 🌐 **Linguagens:** HTML5, CSS3, JavaScript.
* 🛠️ **Ferramentas:** Git, GitHub, Docker.

## 📁 Estrutura de Pastas
* 🎨 `/assets/css` - Arquivos de estilo global e responsividade (mobile).
* 🖼️ `/assets/img` - Ícones e imagens utilizadas na interface.
* ⚙️ `/assets/js` - Scripts contendo a lógica de funcionamento das tarefas.
* 📄 `index.html` - Arquivo principal e estrutura visual da aplicação.

## 💻 Instruções de Instalação
1. Certifique-se de ter o Git instalado em sua máquina.
2. Abra o terminal e faça o clone deste repositório executando o comando:
   `git clone https://github.com/Ricardozan36/Trabalho_DevOps.git`
3. Navegue até a pasta criada:
   `cd Trabalho_DevOps`

## ▶️ Instruções de Execução
Por se tratar de uma aplicação web estática no lado do cliente (Front-end), não é necessária a instalação de bibliotecas ou servidores complexos. 
Basta abrir a pasta do projeto clonado no seu computador e dar um duplo clique no arquivo `index.html` para executá-lo diretamente no seu navegador padrão.
